一、总判断：这些产品共享的不是品类，而是情绪任务

用户不是忠于“种田、乙女、短剧、追星或微恐”，而是忠于能稳定提供情绪价值的系统。

可控情绪

现实情绪拥挤时，产品提供安抚、爽感、尖叫、笑、哭、排毒。

可控关系

NPC、AI、恋人、偶像、队友和同担，提供低风险连接。

可控身份

房间、OC、卡面、周边、评论立场和截图，成为自我叙事。

低风险逃离

进入第二现实，但随时可以退出，不必承担现实后果。

抽象公式：情绪入口 + 可控关系 + 身份表达 + 低风险反馈 + 可分享内容。

五、五类高重合用户原型

1

秩序修复型

靠稳定循环找回掌控感。

星露谷、牧场、波西亚、沙石镇、戴夫、桌面挂机。

2

关系投射型

想被看见、被偏爱、被回应。

深空、星野、猫箱、造梦、女性短剧、追星。

3

表达创作型

把脑内世界做出来。

Gacha、Tomodachi、心动、AI 创作。

4

情绪宣泄型

想笑、想骂、想一起尖叫。

女性短剧、脱口秀、超自然行动组。

5

低压社交型

想连接别人，但不想太累。

心动、超自然、追星、线下演出。

六、为什么这些产品用户会重合？

1. 用户按状态切换产品

累了需要 Cozy；孤独时要 AI/乙女；委屈时刷短剧；无聊时玩微恐；想归属时追星或开黑。

2. 关系是最大公约数

NPC、AI、虚拟恋人、偶像、同担、队友、评论区，本质都是低风险连接。

3. 弱社交替代强社交

用户喜欢有人在，但不喜欢被公会、排行、语音、现实身份和日常任务绑架。

4. 它们都能生成可分享身份

房间、卡面、OC、票根、应援、评论立场和开黑名场面，都会成为用户自我叙事。

5. 女性用户不只要甜

她们同时需要陪伴、清算、发泄、高光、创作、共同体和安全刺激。

6. 安全刺激是关键增量

戴夫和超自然说明，休闲用户能接受刺激，只要后果轻、惩罚低、氛围好。

七、产品机会与设计原则

Cozy 经营 + 轻刺激 + 低压社交

例如小镇生活 + 微恐任务，森林采集 + 夜间咖啡馆，组队探险 + 家园展示。

AI 角色进入生活模拟

把 AI 做成小镇 NPC、恋人、宠物、队友，重点是长期记忆、人设稳定和关系事件。

女性向互动短剧 / 互动乙女

短剧提供情绪效率，乙女提供关系资产；组合后是高密度剧情 + 长期偏爱。

Gacha / OC + AI 剧场工具

帮用户更快生成角色设定、对白、分镜、短视频脚本和关系冲突。

应该做不要做
每天有一点变化；关系有记忆；社交低压；表达可分享；刺激低惩罚。把 Cozy 做成上班；让 AI/角色失忆；用广告打断亲密关系；制造攀比和社交焦虑。

八、最终结论

这批产品共同指向一个趋势：游戏和内容正在从“挑战系统”转向“情绪栖息地”。

最值得关注的组合是：长期关系 + 高密度情绪 + 可表达身份 + 低压社交 + 低风险逃离现实。这解释了为什么看似差异巨大的产品，会共享同一批用户。
